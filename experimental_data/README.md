# General

This directory contains the experimental data used for the publication

`dimerization` contains the experimental data of the DOSY-NMR measurement, as well as the experimental data of the in-situ IR measurement and the generated csv files

`irradiations` contains the NMR files measured before and after the irradiations, as well as the excel sheets used for the calculation of yields and conversion, for the screening of additives, dual irradiation experiments, kinetic measurements and the identification of the product and side products

`synthesis` contains the experimental data for the used ligands and complexes

`ultra-fast_spec` contains the experimental data for the resonance Raman and emission spectroscopy (rr_and_emm), the transient absorption measurements (transient_abs) and UV/Vis spectroscopy (uv_vis)
