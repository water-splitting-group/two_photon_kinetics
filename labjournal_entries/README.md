# General

This directory contains the labjournal entries.

Each subdirectory contains the directory `prep_work` containing preparative works like solvent preparation, calibration for the conducted experiments

`dimierization` contains the labjournal entries of the DOSY-NMR and in-situ IR measurments

`equipment` contains the labjournal entries of the used devices in the other directories

`general_protocols` contains the labjournal entries of the used general protocols in the other directories

`irradiation_setup` contains the labjournal entries of the holder newly designed for 2 NMR tubes

`irradiations` contains the labjournal entries for all irradiation experiments (additive screening, dual irradiation experiments, oxygen measurements and side product identification)

`synthesis` contains the labjournal entries of the synthesis of the ligands and complexes

`ultra-fast_spec` contains the labjournal entries for the preparation of the samples for ultra-fast spectroscopy measurements
