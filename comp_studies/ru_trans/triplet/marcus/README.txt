Within the portrayed Marcus-Theory the geometry was linear interpolated between the 3MC and 3MLCT structure. Within the files interpolated.geom_xxx.xyz each geometry can be found, where xxx is a placeholder for the corresponding geometry. Additionally, the trajectory is stored in trajectory.xyz. For each structure the same input as portrayed in Geometry0 is used. Therefore, the .log as well as .fchk file is just provided for this.
