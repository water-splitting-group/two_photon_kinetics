# General

This directory contains the used scripts and files for the data evaluation used for the publication

`dimerization` contains the excel sheet for the calculation of the hydrodynamic radius from the DOSY-NMR measurements, as well as the python scripts used for the evaluation of the in-situ IR measurements

`ir` contains the python scripts used for the plotting and string generation of the IR data

`irradiations` exemplary excel sheets for calculation of the yields and conversion, as well as the python script used for the data plotting

`synthesis` contains the experimental data for the used ligands and complexes

`ms` contains the python script for the plotting of the ESI-MS data

`o2` contains the python script for the plotting of the oxygen measurement data

`ultra-fast_spec` contains the origin files used for the evalution of for the resonance Raman and emission spectroscopy (rr_and_emm), the transient absorption measurements (transient_abs) and UV/Vis spectroscopy (uv_vis), as well as the generated plots

`uv_vis_and_solubility` contains the excel file and python script for the evaluation of the UV/Vis spectroscopy data
